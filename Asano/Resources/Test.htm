Thought for 10s

The first step is not to fit the final formula yet.

The first step is to reduce each (gain, offset) block into one simple line.

For a fixed gain and fixed offset, the only thing changing is midVoltage, which moves sensor1 through a range of values. So within that group, we treat the measured data as:

sensor2 = m * sensor1 + b

where:

m = slope
b = intercept

So for each block of rows with the same raw gain and same raw offset, we do a plain linear fit of:

x = sensor1
y = sensor2

The result is one line per (gain, offset) pair.

Why this helps: the differential-amp-like behaviour can be rewritten as:

sensor2 = centre - multiplier * (sensor1 - centre)

Expanding that:

sensor2 = -multiplier * sensor1 + centre * (1 + multiplier)

So compared with the fitted line:

sensor2 = m * sensor1 + b

we get:

multiplier = -m

and the centre point is the place where sensor1 == sensor2.

Set:

sensor1 = sensor2 = centre

Using the line:

centre = m * centre + b

so:

centre * (1 - m) = b

therefore:

centre = b / (1 - m)

That’s the key first reduction.

So each (gain, offset) group gives us:

slope m
intercept b
effective multiplier = -m
centre = b / (1 - m)

At this stage we are not yet trying to say how gain or offset affect those values. We’re just measuring what each fixed setting actually did.

A C#-ish sketch of this first step:

foreach (var group in rows.GroupBy(r => new { r.Gain, r.Offset }))
{
    // Fit sensor2 = m * sensor1 + b
    var fit = LinearFit(
        x: group.Select(r => r.Sensor1),
        y: group.Select(r => r.Sensor2));

    double m = fit.Slope;
    double b = fit.Intercept;

    double effectiveMultiplier = -m;
    double centre = b / (1.0 - m);

    SaveGroupResult(
        gain: group.Key.Gain,
        offset: group.Key.Offset,
        slope: m,
        intercept: b,
        effectiveMultiplier: effectiveMultiplier,
        centre: centre);
}

A very simple linear-fit implementation is:

static (double Slope, double Intercept) LinearFit(IEnumerable<double> xs, IEnumerable<double> ys)
{
    var x = xs.ToArray();
    var y = ys.ToArray();

    double xMean = x.Average();
    double yMean = y.Average();

    double numerator = 0;
    double denominator = 0;

    for (int i = 0; i < x.Length; i++)
    {
        double dx = x[i] - xMean;
        double dy = y[i] - yMean;

        numerator += dx * dy;
        denominator += dx * dx;
    }

    double slope = numerator / denominator;
    double intercept = yMean - slope * xMean;

    return (slope, intercept);
}

The important mental model is:

raw rows
  ↓
group by gain + offset
  ↓
fit one sensor1→sensor2 line per group
  ↓
extract centre and multiplier from each line

After that, the remaining stages are:

  1. Fit effective multiplier from raw gain
    Use the per-group effectiveMultiplier values and fit them against raw gain.
  2. Fit centre from raw offset
    Use the per-group centre values and fit them against raw offset.
  3. Combine those two fitted relationships
    Produce:

multiplier = f(gain)
centre = g(offset)

  1. Invert the amplifier model
    Starting from:

sensor2 = centre - multiplier * (sensor1 - centre)

rearrange to:

sensor1 = centre + (centre - sensor2) / multiplier

  1. Test the final estimate against measured sensor1
    Compare error, RMSE, worst cases, and look for systematic drift.
  2. Decide whether simple linear fits are enough
    If needed, add small quadratic terms, but only if they clearly improve the result rather than just fitting noise.
